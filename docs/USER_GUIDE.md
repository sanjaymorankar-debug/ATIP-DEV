# ATIP user guide

This guide is for the owner running ATIP day to day: what runs when, what each page is for, how to switch features on, and what to do when something looks wrong.

- **Architecture, security and operations:** `PRODUCTION_ARCHITECTURE.md`, `SECURITY_ARCHITECTURE.md` and `OPERATIONS_RUNBOOK.md`.
- **Every HTTP endpoint:** `API_REFERENCE.md` (generated by `python -m ops api-docs`).

## 1. Starting and stopping

| What | Command |
|---|---|
| Normal start: scheduler, dashboard and live feeds | `python main.py` (from `/Users/agtci/Documents/Project_Documents/Projects/ATIP`) |
| Dashboard | http://127.0.0.1:8000 |
| Pipeline status today | `python main.py --status` |
| Run one job now | `python main.py --run postmarket` (also `premarket`, `intraday`, `weekly`, `overnight`) |
| Health of every component | `python -m ops status` |
| Is live trading off? | `python -m ops safety` |

**Always restart with bare `python main.py`.** `--dashboard` starts the web server only, and the scheduler (and the 16:05 post-market run) silently stops.

## 4. Switches (atip_data/config.json)

Everything new since W27 is **off or read-only by default**. Flip a switch only after reviewing that wave's handoff in `docs/W27…W33_*_HANDOFF.md`.

| Switch | Default | Effect |
|---|---|---|
| `fundamentals.score_enabled` | false | SPI / FS (NSE filings) enter the ATIP score |
| `institutional.score_enabled` | false | INS adds mutual-fund, insider and promoter-trend inputs |
| `fundamentals_enabled` | true | Weekly NSE fundamentals ingestion (data only) |
| `live_feed.stocks_enabled` | false | Stock-level WebSocket feed with REST failover |
| `news.ai_enabled` / `news.daily_cost_cap_usd` | false / 1.0 | Claude Haiku 4.5 news classification + brief (needs a working `ANTHROPIC_API_KEY`) |
| `intraday_scans.enabled` / `.times` | true / 10:30, 12:30, 14:45 | Intraday scans |
| `execution.protective_stops` | false | Child SL-M after a paper entry fills |
| `execution.block_on_broker_health` | true | No new BUY while broker health is DOWN / STALE |
| `futures.enabled` | false | Paper stock-futures short legs (pairs / long-short with `short_via_futures`) |
| `ops.backup_offsite_dir` | unset | Folder for encrypted off-site backup copies |
| `ops.restore_drill_enabled` | true | Sunday restore drill |
| `audit.offbox_dir` | unset | Folder for audit-log segments |

Secrets do not belong in config.json any more. Use these:
- `python -m ops keygen` (once);
- `python -m ops vault-migrate --apply` moves the Dhan / Telegram / Kite credentials into the encrypted vault;
- `echo <value> | python -m ops vault-set NAME` stores a single one.

## 5. Routine tasks

| Task | How |
|---|---|
| Renew the Dhan token (daily) | Generate it at Dhan, then `echo <token> \| python -m ops vault-set DHAN_ACCESS_TOKEN` (or the old config key). Broker health shows `dhan_token DOWN` when it has expired |
| Zerodha login (daily) | `/trading` → "Log in to Zerodha", or `python main.py --login-zerodha`. The redirect URL registered at Kite must be `http://127.0.0.1:8000/zerodha/callback` |
| First fundamentals backfill | `python -m data.nse_filings` then `python -m data.institutional` (about an hour, off-hours) |
| IV history backfill | `python -m data.derivatives --backfill 250 --recompute` |
| Backup now / list / restore drill | `python -m ops backup`, `python -m ops backups`, `python -m ops restore-drill` |
| Rollback drill (safe) | `python -m ops rollback-drill --to <tag>`: a scratch clone on port 8078, never production |
| Key rotation | `python -m ops rotate-key` (dry run), then `--apply`. Take a backup afterwards, then delete `ATIP_ENCRYPTION_KEY.previous` |
| Regenerate the API reference | `python -m ops api-docs` |

## 6. Troubleshooting

| Symptom | Likely cause / check |
|---|---|
| Scores stale after 16:05 | The scheduler is not running (ATIP was started with `--dashboard`); `python main.py --status` |
| Broker health `dhan_token DOWN` | The Dhan access token has expired; renew it (above) |
| Broker health `quote_freshness STALE` | The live feed / REST quotes stopped; check `/market` feed status and atip.log. New BUYs are blocked meanwhile |
| Reconciliation BREAKS | `/trading` → Execution operations lists each break. "explained" rows are non-OMS paper orders, not errors |
| Market brief says "rule-based — not AI" | `news.ai_enabled` is off, the API key is rejected (KD-001), or today's cost cap is reached (shown on the card) |
| A strategy never trades | `/strategies` health issues; `/ml` AI-strategy gates for ML strategies; risk decisions on `/trading` say which check failed |
| Futures short REJECTED "one lot exceeds the position target" | Stock-futures lots are ~₹5–10 lakh notional; the paper book needs crores |
| `/health/*` DEGRADED after a deploy | `python -m ops release postcheck`; the rollback procedure is `docs/ROLLBACK_PROCEDURE.md` |

## 7. What ATIP will not do

- **No live orders.** The Dhan adapter refuses every call, LIVE futures are refused, and Kite orders are not built.
- **No hidden enabling.** It never enables live trading or any of the switches above by itself.
- **No secrets in output.** It never prints a secret or returns one through the API.
- **No unencrypted off-site copies.** It never copies an unencrypted database off-site unless `ops.backup_offsite_plaintext` is explicitly true.
