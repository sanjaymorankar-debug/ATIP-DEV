## Batch 1 — PERF-001 detail (PERF-001-01 … -14)

An audit found none of the 14 requirements missing outright, but most were only partly met. Fixed:

| Req | Change |
|---|---|
| 01 data model | **Bug:** paper `PARTIALLY_FILLED` orders never reached `perf_ledger`, so later sells were capped as EXCESS_SELL. Also added: DEPOSIT / WITHDRAWAL cash kinds; `order_ref`, `signal_ref` and `fee_breakdown` columns; `entry_seq`, a portable entry order. **Bug:** MySQL has no `rowid`, so the ledger could not be read there. Migration 0006 numbers the existing rows inside one transaction. |
| 03 executable | A missing volume history is flagged `liquidity UNKNOWN` (it used to pass silently). The exit is liquidity-checked too. |
| 04 actual | Realized P&L, fees and dividends are now reported twice, with labels: for the period and lifetime-to-end. **Bug:** they used to be lifetime while gain and TWR were for the period, and signal attribution mixed the two scopes. |
| 06 costs | Dividend TDS and capped-sell fees are now counted. The reconciliation is an independent `SUM` over `perf_ledger` for the period. Added: recorded fee components, and an itemised NSE statutory estimate (clearly an estimate) for trades without a breakdown. |
| 07 / 09 attribution | A buy carrying `signal_ref` links to its signal exactly; otherwise the window rule applies. New sizing effect, so that entry + averaging + exit + costs + sizing = actual − model P&L on the model notional. |
| 10 portfolio | New Euler risk contribution: the shares sum to 100 % and reconcile to portfolio volatility. New cash account: the whole-account TWR with DEPOSIT / WITHDRAWAL rows. |
| 11 dashboard | Days invested are shown. The overview card now shows all four returns. |
| 12 audit | The audit records content sha256 of the ledger, signals and prices, the last price date per series, `CALCULATION_VERSION` and basis fallbacks. New `verify()` + `GET …/reports/{id}/verify` rebuilds a saved report and diffs it. |
| 13 export | The CSV carries every section, copied rather than recomputed. New strategy filter and preview-export route. |
| 14 edge cases | Holiday, missing bars, bonus, OPENING, cash and partial fill are covered. |

**Tests:** `tests/test_w39_performance_detail.py` (24). The expected numbers are computed by hand.

## Batch 2 — owner notes

- **DP-23, 7-year history.**
  - New `data/history_backfill.py`, a year-window backfill of the tracked universe plus indices. It goes through `run_historical_pipeline`, which now takes `start_date` and `basis_date`.
  - It is resumable, remembers listing dates, and retries refused windows.
  - **Bug:** the weekly purge deleted every `prices_daily` row older than 600 days. It now keeps `history_years` (default 7).
  - CLI: `python main.py --backfill-history [--history-years N] [--backfill-dry-run]`.
  - A weekly Sunday top-up runs it automatically. Status is at `/api/data/history/status`.
- **OPS-12, Dhan TOTP renewal.**
  - The scheduler now renews the token daily at 06:45, and at start-up when it is dead.
  - Until now only a Windows scheduled task did this, so on macOS the token expired daily.
  - `config_template.json` documents `dhan_pin` and `dhan_totp_secret` (left empty) and the switches.
- **DB-20, stock history.**
  - New ranges: 3Y, 5Y, All.
  - Daily, weekly and monthly bars.
  - Overlays: SMA 20 / 50 / 200, EMA 21, Bollinger.
  - Log scale, and multi-year returns.
  - Checked in headless Chromium.
- **DP-21, AMFI.** This already existed (`mf_nav`, daily); the tracker now says so.

## Batch 4 — Zerodha / Dhan parity and UX

- **EX-18, basket orders** (`orders/basket.py`, `/baskets`).
  - Preview dry-runs every leg through the existing order path and runs one funds check for the whole basket.
  - Placement is all-or-nothing at the gate, with SELL legs first.
  - A partial result is reported as PARTIAL.
- **EX-20, stock SIP** (`orders/sip.py`).
  - Monthly or weekly plans, by amount or quantity.
  - PAPER only: SANDBOX / LIVE record `SKIPPED_NOT_PAPER` and send nothing.
  - One execution per due date, 3 attempts, then MISSED.
- **UX-01, progressive disclosure.** A Simple / Detailed toggle on `/wealth`, where Simple hides the audit, ledger and trade-level tables.
- **Already present, now noted in the tracker:** intraday price alerts (ENT-11) and watchlists (ENT-19).
